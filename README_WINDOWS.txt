DARK AUDIO CHANGER - Windows (installer nahi chahiye)

1. Poora zip Extract karo (kisi bhi folder me, jaise Desktop).
2. DarkAudioChanger.exe par double click karo.
3. App ki window khulegi. Video chuno aur "DUB SHURU KARO" dabao.

Dhyan rakhein:
- Internet chahiye (translation aur Hindi awaaz online banti hain).
- Pehli dubbing me Whisper model (~460 MB) apne aap download hoga, isliye pehli baar zyada time lagega.
- Dub ki hui video: SAVE KARO dabane par Downloads\DarkAudioChanger me jati hai.
- Behtar translation ke liye .env.example ka naam .env karo aur ANTHROPIC_API_KEY daalo (optional).
- Window na khule to Windows ko "WebView2 Runtime" chahiye (Microsoft se free).
- Error aaye to DarkAudioChanger.log file mujhe bhejo.
